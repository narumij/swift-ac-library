# Progress Overview History

最終更新: 2026-10-08 / Codex

この文書は、`Maintanance/PROGRESS_OVERVIEW.md`の現行Task Registryから退避したtaskの履歴正本である。
現行taskの状態判断には使わず、Registryに残された移動先から必要な場合だけ参照する。

## Archive rules

- `DONE`または`EXCLUDED`で、現行Registryの可読性を下げるtaskだけを退避する。
- task IDは変更・再利用しない。
- 退避時にID、最終状態、結果、関連commit、元の詳細正本を記録する。
- 現行Registryには`ARCHIVED`行を残し、この文書の該当anchorを移動先として示す。
- `ACTIVE`、`WAITING_USER`、`WAITING_EXTERNAL`、`FROZEN`、`USER_ONLY`は退避しない。
